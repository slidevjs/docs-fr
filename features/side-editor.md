# Éditeur intégré

Slidev dispose d'un éditeur intégré qui rechargera instantanément et enregistrera les modifications dans votre fichier.

Cliquez sur le bouton <carbon-edit class="inline-icon-btn"/> sur le panneau de navigation pour l'ouvrir.
