## Démarrer le serveur localement

```
npm i -g pnpm

pnpm i
pnpm run dev
```

Puis visitez `http://localhost:3000`

Ou installez l'[extension Vite pour VS Code](https://marketplace.visualstudio.com/items?itemName=antfu.vite) pour éditer côte à côte.
